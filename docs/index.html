⚙️ Cómo usar estos datos

Fetch directo desde JavaScript

const BASE = "https://TU_USUARIO.github.io/jujuy-estadisticas";

// Cargar tasas laborales
const res  = await fetch(`${BASE}/data/json/tasas_laborales.json`);
const data = await res.json();
console.log(data.datos); // array de objetos por año y región

Leer el CSV en Python con pandas

import pandas as pd

BASE = "https://TU_USUARIO.github.io/jujuy-estadisticas"
df = pd.read_csv(f"{BASE}/data/csv/sector_publico.csv")
print(df[["año","resultado_financiero"]])

Índice general de datasets

fetch(`${BASE}/data/json/indice.json`)
  .then(r => r.json())
  .then(idx => console.log(idx.datasets));
